# .github

Organisation-level GitHub configuration for **OpenFSP**.

[Version française](README.fr.md)

[`profile/README.md`](profile/README.md) renders as the organisation profile page at
<https://github.com/openfspht>; [`profile/README.fr.md`](profile/README.fr.md) is its
translation, linked from that page.

The specification and the ADR process are in [`adrs`](https://github.com/openfspht/adrs);
the governance documents are in [`openfsp`](https://github.com/openfspht/openfsp).

## Editing this repository

I change both language versions together, in the same commit. English is the reference
where they disagree.
