# .github

Organization-level GitHub configuration for **OpenFSP**.

[Version française](README.fr.md)

[`profile/README.md`](profile/README.md) renders as the organization profile page at
<https://github.com/openfspht>; [`profile/README.fr.md`](profile/README.fr.md) is its
French version, linked from that page.

The specification and the decisions are published on [openfsp.org](https://openfsp.org),
the code is in [`openfsp`](https://github.com/openfspht/openfsp), and the governance
documents are in [`governance`](https://github.com/openfspht/governance).

## Editing this repository

We change both language versions together, in the same commit. English is the reference
where they disagree.
