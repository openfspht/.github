# .github

Organisation-level GitHub configuration for **OpenFSP**.

[Version française](README.fr.md)

[`profile/README.md`](profile/README.md) renders as the organisation profile page at
<https://github.com/openfspht>.

Nothing else lives here. The specification, the RFC process and the governance documents
are in the [`openfsp`](https://github.com/openfspht/openfsp) repository.

## What OpenFSP is

An open standard for payment interoperability in Haiti: a protocol, a self-hosted gateway
that implements it, a mock server for testing without a merchant account, and thin client
SDKs.

Apache-2.0 throughout. Stewarded by [Karako Systems](https://karakosystems.com).

## Editing this repository

Both language versions are kept in step. A change to one is a change to the other, in the
same commit; English is the reference where they disagree.
