# .github

Configuration GitHub au niveau de l'organisation **OpenFSP**.

[English version](README.md)

[`profile/README.fr.md`](profile/README.fr.md) est la version française de la page de
profil de l'organisation, publiée à <https://github.com/openfspht>.

Rien d'autre ne vit ici. La spécification, le processus RFC et les documents de
gouvernance sont dans le dépôt [`openfsp`](https://github.com/openfspht/openfsp).

## Ce qu'est OpenFSP

Une norme ouverte d'interopérabilité des paiements en Haïti : un protocole, une passerelle
auto-hébergée qui l'implémente, un simulateur pour développer sans compte marchand, et des
bibliothèques clientes légères.

Apache-2.0 partout. Projet porté par [Karako Systems](https://karakosystems.com).

## Modifier ce dépôt

Les deux versions linguistiques sont tenues à jour ensemble. Un changement dans l'une est
un changement dans l'autre, dans le même commit ; l'anglais fait foi en cas de divergence.
