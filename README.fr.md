# .github

Configuration GitHub de l'organisation **OpenFSP**.

[English version](README.md)

GitHub affiche [`profile/README.md`](profile/README.md) comme page de profil de
l'organisation, à <https://github.com/openfspht> ; [`profile/README.fr.md`](profile/README.fr.md)
en est la version française, liée depuis cette page.

La spécification et les décisions sont publiées sur [openfsp.org](https://openfsp.org/fr),
le code se trouve dans [`openfsp`](https://github.com/openfspht/openfsp) et les documents de
gouvernance dans [`governance`](https://github.com/openfspht/governance).

## Modifier ce dépôt

Nous modifions les deux versions ensemble, dans le même commit. En cas de divergence, l'anglais
fait foi.
